# Agenda de Contactos - Ejercicio C# .NET

Aplicación básica de consola en C# (.NET) para gestionar una agenda de contactos, desarrollada y probada en JetBrains Rider.

## Requisitos Previos

* [.NET SDK](https://dotnet.microsoft.com/download) (versión 10.0).
* [JetBrains Rider](https://www.jetbrains.com/rider/).

---

## Cómo Ejecutar la Aplicación

Puedes ejecutar la aplicación de dos formas:

### Opción 1: Desde JetBrains Rider
1. Abre el proyecto en Rider.
2. Localiza el proyecto principal en el explorador de soluciones.
3. Haz clic en el botón verde **Run** (o presiona `Shift + F10`).

### Opción 2: Desde la Terminal / Línea de Comandos
1. Abre tu terminal y navega hasta la carpeta del proyecto principal.
2. Ejecuta el comando:
   ```bash
   dotnet run
